# ResponseOne Demo Application

A small Flask application used as the target application for the
ResponseOne DevSecOps and SOAR project.

The application will be integrated with:

- Semgrep — SAST
- Trivy — dependency/container scanning
- Gitleaks — secrets detection
- OWASP ZAP — DAST
- GitHub Actions — CI/CD
- SOAR — automated triage and response
- PostgreSQL — findings storage
- Grafana — security metrics and dashboarding
